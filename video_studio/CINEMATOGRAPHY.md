# Production visual bible

These principles are implemented through the per-scene storyboard and prompt workflow.

- Write the narrative and verify factual claims before imagery.
- Establish a **visual bible**: era, location, recurring characters, wardrobe, physical attributes, weather, colour grade, focal length, lens, lighting, grain and aspect ratio.
- Write one shot per clear narrative beat. Reuse a reference frame and previous clip continuity whenever supported by the provider.
- Use image-first generation for precise composition; animate only shots that benefit from motion.
- Use archival source imagery when licensed and accurate. Mark photorealistic reconstructions as reconstructions when needed.
- Never call all-AI footage archival. Sources should remain attached to the editorial project.
- Use a short hook for vertical clips but preserve factual qualifications.
- QA should check temporal continuity, anatomy, physical implausibilities, typography, flickering and nonsensical artifacts.
- Render at 24 fps, H.264 1080p; keep a separate caption track.
- Capture video generation costs and allow per-shot regeneration; never silently regenerate an entire episode.
